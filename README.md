# nuxt-pnpm-workspace-template

A simple scaffolding for building nuxt apps with pnpm workspace.

## Apps
> ### Setup a new app by running:
> ```bash
> cd apps && pnpx giget@latest gh:hareland/nuxt-app-template <app-name>
>```
